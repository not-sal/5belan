5belan for Linux (x86_64 or ARM64, with a desktop)

1. Extract this archive anywhere you want to keep the app, for example your home folder:
       tar xzf 5belan-linux.tar.gz
2. Open a terminal in the extracted 5belan folder and run:
       bash install.sh
   (internet needed; takes a few minutes the first time)
3. Start it from the app menu or the desktop icon "5belan", or run ./run.sh
4. First start: open Settings (bottom of the sidebar) and paste your DeepSeek API key.

Updates: the app checks for updates by itself and shows a banner at the top of the chat.
Your chats and settings are kept in ~/.local/share/5belan and are not touched by updates or reinstalls (chats from an older install are imported automatically on first start).
If the window does not open, read launch.log in this folder.
